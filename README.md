# Web-Development.part-2
Natures' Garden Name: Ayanda Nomfundo Msimango ST10534547

Natures' Garden is a simple website created for a natural products business. The website is designed to provide customers with information about the business and the natural products it offers.

The website includes information about Natures' Garden, its products, and how customers can get in contact with the business. The main products featured on the website are Herbal Gummies, Herbal Tea, and Collagen Powder.

The website was developed using HTML and CSS as part of a Web Development project. The aim of the project is to create a simple, clear, and user-friendly website that presents the business and its products in an organised way.

Goals

To create a professional and user-friendly website for Natures' Garden.
To provide customers with information about the business and its natural products.
To showcase the products offered by Natures' Garden.
To make information about the products easy to find and understand.
To create an online presence for the business.

## About the Website

Natures' Garden is a nature-inspired website created for a business that provides natural and organic products designed to support healthier lifestyles.

The website provides information about the business, its products, customer reviews, and ways to contact the business.

## Website Pages

The website includes the following pages:

- **Home** - Introduction to Natures' Garden and an overview of the products.
- **About Us** - Information about the business, mission, vision, and values.
- **Products** - Displays the available products, descriptions, images, and prices.
- **Reviews** - Displays customer feedback and ratings.
- **Contact Us** - Provides contact information and an enquiry form.
- **Enquiries** - An additional enquiry page from the original website structure.

## Products

The website currently features:

- 🌿 Herbal Tea
- 🌸 Herbal Gummies
- 🍃 Collagen Powder

## Design

The website uses a natural and calming color palette inspired by nature:

- Deep Forest Green
- Sage Green
- Cream
- Warm Beige
- Soft Brown
- Eucalyptus Green

The typography includes:

- **Garamond** for headings
- **Calibri** for body text
- **Century Gothic** for buttons
