# Web-Development.part-2
Natures' Garden Name: Ayanda Nomfundo Msimango ST10534547

Natures' Garden is a simple website created for a natural products business. The website is designed to provide customers with information about the business and the natural products it offers.

The website includes information about Natures' Garden, its products, and how customers can get in contact with the business. The main products featured on the website are Herbal Gummies, Herbal Tea, and Collagen Powder.

The website was developed using HTML and CSS as part of a Web Development project. The aim of the project is to create a simple, clear, and user-friendly website that presents the business and its products in an organised way.

Goals

To create a professional and user-friendly website for Natures' Garden.
To provide customers with information about the business and its natural products.
To showcase the products offered by Natures' Garden.
To make information about the products easy to find and understand.
To create an online presence for the business.
Objectives

Develop a website using HTML and CSS.

Create clear and organised website pages.

Display the three main products: Herbal Gummies, Herbal Tea, and Collagen Powder.

Provide information about the business and its products.

Include a contact page where customers can find information on how to communicate with the business.

Make the website simple to navigate and visually appealing.

Key features Navigation Menu: Allows users to easily move between the different pages of the website.

Home Page: Introduces Natures' Garden and provides an overview of the business.

About Us Page: Provides information about the business, its purpose, mission, and vision.

Products Page: Displays the products offered by Natures' Garden, including Herbal Gummies, Herbal Tea, and Collagen Powder.

Product Images: Uses images to make the products easier for users to identify and understand.

Contact Page: Provides customers with contact information for the business.

Simple Layout: Uses a clear and organised layout to make the website easy to navigate.

Responsive Design: The website is designed to display properly on different screen sizes.
